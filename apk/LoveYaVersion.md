# LoveYa APK 版本记录

## 版本规则
- 测试阶段命名：`LoveYa_Test_${版本号}`
- 正式版命名：`LoveYa_${版本号}`
- 版本号格式：`${主版本号}.${次版本号}.${修订版本号}`
- 版本号必须递增，默认只递增修订版本号
- BUG测试版本的修订版本号不为 0，相关 apk 和更新描述放在 `apk/sub-test-apk/` 目录
- 主版本号/次版本号变更且修订版本号为 0 时（正式版），更新 `apk/` 根目录的 apk 及 md 文件

## LoveYa_2.0.0

新增云备份功能

**首个正式版本**

**发布日期**：2026-08-02

**文件大小**：约 25MB

### 主要功能
- 日记功能（添加、查看、删除、标签筛选、搜索、排序）
- 数据手册（添加、查看详情、删除、标签、排序、浪漫 UI）
- 恋爱纪念日（公历/农历切换、倒计时）
- 云备份与还原（基于 Gitee 私有仓库 + 私人令牌）
- 用户管理（注册、登录、切换用户、多设备异地账号找回）
- 开屏界面（浅蓝色主题，显示"雅"、"LoveYa"、"刘威 ❤ 杨欣雅"）
- 设置界面（云备份入口）

### 更新内容（相对 1.1.0）
1. **云备份功能**：基于 Gitee 私有仓库 + 私人令牌实现零服务器成本云备份
2. **用户数据云端同步**：开发者中心仓库统一管理用户账号信息，支持多设备异地账号找回
3. **注册/登录强制联网**：保证账号信息能同步到云端
4. **云备份按用户分目录**：多用户共用同一仓库时数据隔离
5. **JSON 美化输出**：云端数据带缩进换行，便于阅读
6. **R8 混淆修复**：实体类加 @SerializedName 固定 JSON key，修复字段名被混淆问题
7. **数据库迁移修复**：实现真正的数据库迁移策略，升级不再清空数据
8. **农历算法修复**：支持 1900-2100 年转换，月份采用数字显示
9. **云还原刷新修复**：弹窗提示重启，确保数据正确加载

### 主题颜色
浅蓝色（`#0EA5E9`），纯黑色加粗黑体文字

### 已知问题
- 修改用户名/密码功能尚未接入 users.json 同步（当前项目无修改用户名/密码入口，未来加入时需调用 `remoteUserSyncService.upsertUser(...)`）

### 备注
- 云备份为可选功能，不绑定不影响任何本地功能
- 云端 users.json 存储用户账号信息，包含明文密码，仅供账号找回使用
