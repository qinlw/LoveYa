# LoveYa APK 版本记录

## 版本规则
- 测试阶段命名：`LoveYa_Test_${版本号}`
- 正式版命名：`LoveYa_${版本号}`
- 版本号格式：`${主版本号}.${次版本号}.${修订版本号}`
- 版本号必须递增，默认只递增修订版本号
- BUG测试版本的修订版本号不为 0，相关 apk 和更新描述放在 `apk/sub-test-apk/` 目录
- 主版本号/次版本号变更且修订版本号为 0 时（正式版），更新 `apk/` 根目录的 apk 及 md 文件

## LoveYa_3.0.0

新增日历（大姨妈记录与纪念日标记）与全局置顶能力

**发布日期**：2026-10-28

**文件大小**：约 25.3MB（26,495,985 字节）

**版本号**：3.0.0（versionCode 43）

### 主要功能
- 日记功能（标签可编辑、搜索、按标签筛选、排序、左滑置顶、长按批量删除）
- 数据手册（标签、排序、左滑置顶、浪漫 UI）
- 恋爱纪念日（左滑置顶、公历/农历切换、已过天数与倒计时）
- 日历（大姨妈记录与周期推算、纪念日标记、标记搜索）
- 云备份与还原（Gitee 私有仓库，按用户名隔离）
- 用户管理（注册、登录、切换、删除用户）
- 设置界面（存储路径、备份导入导出、日历显示设置）

### 更新内容（相对 2.1.0）

**1. 新增日历页面**

- 底部导航新增「日历」Tab，位于「数据手册」与「我的」之间
- 月视图（周一为每周起始），支持前后翻月
- 记录大姨妈：日期显示粉色圆底
- 纪念日标记：日期下方显示小圆点，按公历月日每年重复
- 点击日期仅选中该日期并在下方展示当天记录，不直接弹出设置
- 顶部「+」用于为选中日期（未选中则为今天）添加记录
- 顶部旋转 90° 的「…」为设置菜单：搜索标记、日历推算
- 日历下方显示上次大姨妈日期、已经过去天数、平均周期、预计下次及倒计时
- 平均周期取最近 6 个周期，自动过滤 15~60 天异常值

**2. 全局置顶（左滑操作，QQ 风格）**

- 日记、数据手册、首页纪念日均支持左滑露出「置顶 / 取消置顶」按钮
- 按钮与卡片同高，宽度 88dp，点击后执行并自动收回
- 置顶项显示浅蓝底色与「图钉 置顶」徽标
- 置顶项始终排在最前，不受排序方式影响
- 置顶操作不会修改内容的更新时间

**3. 排序机制改造**

- 「默认排序」改为按**最后更新时间**（updatedAt）排序
- 「时间排序」改为按**创建时间**（createdAt）排序
- 日记页新增排序类型下拉（默认 / 时间），与数据手册保持一致
- 所有排序均置顶优先

**4. 首页体验优化**

- 纪念日悬浮加号改为**可拖动**，可自由调整位置（限制在屏幕范围内，不会拖出边界）
- 公历与农历日期换行显示，避免过长时 UI 变形
- 生日倒计时支持点击标题切换公历/农历（我的生日与爱人生日独立设置）
- 纪念日卡片新增「已经 XX 天」显示

**5. 其他修复与优化**

- 修复设置页日历类型切换不持久化的 BUG（生日/爱人生日/开始日期独立按用户存储）
- 日记、数据手册详情页支持标签编辑，保存时同步更新
- 新建日记的标题改为 placeholder 灰色显示，输入后消失
- 数据备份新增日历标记（calendarMarks），导入旧备份时自动兼容

### 数据库变更

- 版本 5 → 6：`diary`、`data_book` 新增 `is_pinned` 字段；新增 `calendar_mark` 表
- 版本 6 → 7：`anniversary_config` 新增 `is_pinned` 字段
- 均为增量迁移，升级不丢失既有数据

### 升级说明

- 可从 2.1.0 直接覆盖安装，首次启动自动完成数据库迁移
- 备份 JSON 版本仍为 1.2，旧备份可直接导入

## LoveYa_2.1.0

账号体系重构，UI 统一

**发布日期**：2026-08-02

**文件大小**：约 25MB

### 主要功能
- 日记功能（详情页可编辑标题和内容、列表长按删除、保存悬浮提示）
- 数据手册（详情页可编辑名称和内容、UI对齐日记）
- 用户管理（注册时占用用户名、删除用户、仅可改密码）
- 云备份与还原（按用户名隔离路径、配置按用户隔离存储）
- 开发者模式（设置底部入口，密码=DEV_GITEE_TOKEN，查看仓库配置）

### 更新内容（相对 2.0.0）
1. **取消备份ID概念**：用户名作为账号唯一标识继承备份ID功能，云备份路径改为 `backups/{username}/loveya_backup.json`
2. **注册时占用用户名**：上传用户名到 usersID.json 防同名，注册前先校验云端唯一性
3. **删除修改用户名功能**：用户名不可修改，仅可改密码
4. **修复账号间 Gitee 绑定共享BUG**：配置按用户隔离存储（`cloud_backup_{username}` 文件）
5. **移除 users.json 中 backup_id 旧字段**：RemoteUserEntry 不再包含该字段
6. **修复云还原"不支持的备份版本"BUG**：兼容所有 1.x 版本
7. **切换用户处增加删除用户数据功能**：带二次确认弹窗
8. **数据手册/日记详情页UI重构**：浅蓝色渐变标题区、可编辑名称、删除圆形/心心图标/5点图案
9. **数据手册/日记保存反馈改为屏幕正中悬浮1s提示**：新建 ToastPopup 组件，点击屏幕可提前关闭
10. **开发者模式入口**：设置底部"开发者"按钮，密码=DEV_GITEE_TOKEN

### 主题颜色
浅蓝色（`#0EA5E9`），纯黑色加粗黑体文字

### 已知问题
- 无

### 备注
- 升级后旧版本用户需重新登录一次（云备份配置按用户隔离，旧 `cloud_backup` 文件不再使用）
- 用户名注册后不可修改，请务必牢记

## LoveYa_2.0.0

新增云备份功能

**首个正式版本**

**发布日期**：2026-08-02

**文件大小**：约 25MB

### 主要功能
- 日记功能（添加、查看、删除、标签筛选、搜索、排序）
- 数据手册（添加、查看详情、删除、标签、排序、浪漫 UI）
- 恋爱纪念日（公历/农历切换、倒计时）
- 云备份与还原（基于 Gitee 私有仓库 + 私人令牌）
- 用户管理（注册、登录、切换用户、多设备异地账号找回）
- 开屏界面（浅蓝色主题，显示"雅"、"LoveYa"、"刘威 ❤ 杨欣雅"）
- 设置界面（云备份入口）

### 更新内容（相对 1.1.0）
1. **云备份功能**：基于 Gitee 私有仓库 + 私人令牌实现零服务器成本云备份
2. **用户数据云端同步**：开发者中心仓库统一管理用户账号信息，支持多设备异地账号找回
3. **注册/登录强制联网**：保证账号信息能同步到云端
4. **云备份按用户分目录**：多用户共用同一仓库时数据隔离
5. **JSON 美化输出**：云端数据带缩进换行，便于阅读
6. **R8 混淆修复**：实体类加 @SerializedName 固定 JSON key，修复字段名被混淆问题
7. **数据库迁移修复**：实现真正的数据库迁移策略，升级不再清空数据
8. **农历算法修复**：支持 1900-2100 年转换，月份采用数字显示
9. **云还原刷新修复**：弹窗提示重启，确保数据正确加载

### 主题颜色
浅蓝色（`#0EA5E9`），纯黑色加粗黑体文字

### 已知问题
- 修改用户名/密码功能尚未接入 users.json 同步（当前项目无修改用户名/密码入口，未来加入时需调用 `remoteUserSyncService.upsertUser(...)`）

### 备注
- 云备份为可选功能，不绑定不影响任何本地功能
- 云端 users.json 存储用户账号信息，包含明文密码，仅供账号找回使用
